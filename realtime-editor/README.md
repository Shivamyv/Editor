# 🚀 Realtime Code Editor

A collaborative workspace built with **React**, **Node.js**, and **Socket.io** that allows multiple users to code together in real-time.

## 🛠️ Setup Instructions

### Backend
1. `cd backend`
2. `npm install`
3. `npm start`

### Frontend
1. `cd realtime-editor`
2. `npm install`
3. `npm start`
