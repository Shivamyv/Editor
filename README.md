# 🚀 Real-Time Collaborative Code Editor

A full-stack, collaborative workspace built with **React**, **Node.js**, and **Socket.io**. This application allows multiple developers to join a private room and edit code simultaneously with instant synchronization across all clients.

## ✨ Key Features
* **Live Synchronization**: Any code changes made by one user are instantly reflected for everyone in the room.
* **Room Management**: Generate unique Room IDs to invite collaborators to a specific session.
* **Dynamic Avatars**: Automatically identifies active users in the room with visual initials/avatars.
* **Responsive UI**: A minimalist, dark-themed editor optimized for focus and long coding sessions.

## 🛠️ Tech Stack
* **Frontend**: React.js, Socket.io-client, React-Router.
* **Backend**: Node.js, Express.js, Socket.io.
* **Editor Engine**: Powered by advanced JavaScript logic for real-time string manipulation.
